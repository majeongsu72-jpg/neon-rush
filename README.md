# NEON RUSH — 네온 질주

모든 그래픽·효과음·음악을 **코드로 절차적 생성**한 초고속 3D 아케이드 레이싱 게임입니다.
외부 이미지·모델·오디오 파일이 하나도 없으며, 빌드 결과물은 **더블클릭으로 실행되는 HTML 파일 1개**입니다.

## 바로 플레이하기

**▶ https://majeongsu72-jpg.github.io/neon-rush/** — 설치 없이 브라우저에서 바로 실행

| 방법 | 명령 |
|---|---|
| 웹에서 | 위 링크 (main 브랜치에 push하면 GitHub Actions가 자동으로 다시 배포) |
| 빌드된 단일 파일 | `npm run build` 후 `dist/index.html` 을 더블클릭 (인터넷 불필요) |
| 개발 서버 | `npm install` 후 `npm run dev` → http://localhost:5173 |
| 다시 빌드 | `npm run build` (타입 검사 + 단일 HTML 생성) |

Chrome / Edge 최신 버전을 권장합니다. 첫 화면에서 아무 키나 누르면 사운드가 켜집니다.

## 트랙

| 트랙 | 길이 | 특징 |
|---|---|---|
| **NEON CITY** 네온 시티 | 4.5 km | 비 내리는 사이버펑크 야경. 빌딩 숲 메인 스트레이트, 고가도로 S자, 조명이 쏟아지는 곡선 장터널, 광장 헤어핀, 시가지 시케인, 운하 옆 백스트레이트 |
| **SUNSET COAST** 선셋 코스트 | 5.2 km | 줄무늬 태양이 지는 신스웨이브 해안. 절벽 위 점프 크레스트, 727 m 현수교, 곶을 뚫는 곡선 터널, 회전하는 등대 불빛 아래 헤어핀 |
| **HYPER GRID** 하이퍼 그리드 | 4.4 km | 허공에 뜬 트론풍 서킷. 40° 뱅크 벨로드롬, 360° 수직 루프, 아래 도로 위를 날아 넘는 점프, 270° 나선 하강 교차로, 부스트 패드, 음악 비트에 맞춰 맥동하는 링 게이트 |

## 게임 모드

- **레이스** — 라이벌 7대와 3랩 승부. 4단계 난이도, 실시간 순위 타워, 추월 알림, 결승 슬로모.
- **타임 어택** — 최고 랩을 반투명 홀로그램 고스트로 재생, 실시간 기록 차이(±초), 금·은·동 메달.
- **하이웨이 러시** — 교통 차량 사이를 칼치기. 체크포인트로 시간 연장, 니어미스 콤보 배율, 역주행 차선 ×2.

## 속도감을 만드는 장치들

- 드리프트 3단 부스트(파랑→주황→보라), 니트로, 슬립스트림 → SLINGSHOT, 퍼펙트 스타트, 니어미스 불릿타임
- 속도에 따른 FOV·방사형 블러·색수차·애니 스피드라인, 카메라 셰이크, 라이트 트레일
- 비에 젖은 노면에 번지는 가로등·터널 조명(분석적 조명 셰이더), 차체를 훑고 지나가는 조명 띠
- 불꽃·타이어 연기·스키드마크·니트로 화염 (GPU 파티클), 카메라를 향해 쏟아지는 빗줄기

## 기술 구성

- Vite 8 + TypeScript(strict) + three.js r186 (WebGLRenderer)
- 트랙 좌표계(곡선좌표) 차량 물리 — 뱅크·교차로·수직 루프까지 지원, 120Hz 고정 스텝
- 자체 HDR 포스트 파이프라인(밉체인 블룸 + 단일 합성 패스), 동적 해상도, 품질 프리셋
- AI: 최소 곡률 레이싱 라인 + 속도 프로필 + 허밋 프리뷰 조향 + 추월/러버밴딩
- Web Audio 100% 합성: 차종별 엔진음(RPM·부하 그리드 루프, 터보·백파이어·블로오프), 추월 차량 도플러,
  터널 잔향, 스텝 시퀀서로 연주하는 트랙별 음악 3곡 + 메뉴곡(파이널 랩 레이어, 니트로 필터 스윕)
